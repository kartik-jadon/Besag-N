# BISAG-N modern redesign (demo)

React 18 + Vite + Tailwind CSS 3. Responsive for mobile, tablet and desktop, with light/dark theme, text-size controls and reduced-motion support.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in /dist
```

Content (menu, services, team, achievements) lives at the top of `src/App.jsx`.
Notice board rows are sample data: replace `NOTICES` with your feed.
This is an independent redesign for demonstration, not an official BISAG-N site.
